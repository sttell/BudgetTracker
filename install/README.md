# Установка BudgetTracker

BudgetTracker — локальный трекер личного бюджета. Траты вносятся через Claude (диктовкой, скриншотом или выпиской
из банковского приложения) или руками в веб-интерфейсе; приложение считает остаток месячного бюджета и честный
лимит на день и неделю. Все данные хранятся у вас на компьютере в JSON-файлах — никаких серверов и баз данных.

Что ставится:

| Компонент | Зачем |
|---|---|
| Приложение (Python, ставится через [uv](https://docs.astral.sh/uv/)) | хранение данных, расчёт бюджета, веб-интерфейс на http://localhost:5050 |
| MCP-сервер `budget` в Claude Desktop и Claude Code | через него Claude читает и записывает траты |
| Скилл `budget-tracker` | подсказывает Claude, когда и как работать с бюджетом: включается только на запросы про траты и бюджет |

## Быстрая установка

Нужен установленный [Claude Desktop](https://claude.ai/download). Python, uv и зависимости установщик поставит сам.

**macOS / Linux** — в Терминале:

```bash
curl -fsSL https://raw.githubusercontent.com/sttell/BudgetTracker/main/install/install.sh | bash
```

**Windows** — в PowerShell:

```powershell
irm https://raw.githubusercontent.com/sttell/BudgetTracker/main/install/install.ps1 | iex
```

Установщик:
1. ставит `uv`, если его нет (а он сам скачает нужную версию Python);
2. скачивает приложение в `~/BudgetTracker` (Windows: `%USERPROFILE%\BudgetTracker`);
3. ставит зависимости;
4. прописывает MCP-сервер `budget` в конфиг Claude Desktop (старый конфиг сохраняется рядом как
   `claude_desktop_config.json.bak-<дата>`), а если есть Claude Code — регистрирует сервер и скилл и там;
5. собирает архив скилла `dist/budget-tracker-skill.zip`.

### Два шага руками

1. **Полностью перезапустите Claude Desktop** — выйдите из приложения (macOS: ⌘Q; Windows: «Выход» в трее) и
   откройте снова. Проверка: Settings → Developer — в списке есть `budget`.
2. **Загрузите скилл**: Settings → Capabilities → Skills → Upload → файл
   `~/BudgetTracker/dist/budget-tracker-skill.zip`. (Загрузку скиллов в Claude Desktop нельзя автоматизировать.)

### Первая настройка

Напишите в любом чате Claude: «открой мой бюджет» — агент поднимет веб-интерфейс и пришлёт ссылку. Или откройте
http://localhost:5050 после команды `uv run --directory ~/BudgetTracker budget-web`. В разделе **Настройки** задайте:

- **базовую валюту** (в ней показывается всё) и **валюту ввода** по умолчанию;
- **таргет на месяц** — сколько всего вы готовы тратить за месяц;
- **фиксированные ежемесячные траты** (аренда, коммуналка, спортзал…) — они вычитаются из таргета 1-го числа,
  остаток делится на дни месяца;
- при желании — **реальный курс обмена**, если вы меняете валюту не по официальному курсу.

То же можно сделать в чате: «поставь таргет 3000 €», «добавь фиксированные: квартира 1500 €, коммуналка 20000 динар».

## Как пользоваться

- **Записать траты**: «вчера 800 динар на шаурму и такси 1200», или пришлите скриншот / PDF-выписку из банка —
  агент покажет черновик и запишет после подтверждения.
- **Узнать бюджет**: «сколько я могу потратить сегодня?», «итог месяца», «куда ушли деньги в октябре?».
- После каждой записи агент коротко показывает остаток на день, неделю и месяц и присылает ссылку на веб-интерфейс.
- **Веб-интерфейс**: дашборд, календарь с лимитом и фактом по дням, список операций с фильтрами, ручной ввод.

Как считается бюджет — в [docs/DESIGN.md](../docs/DESIGN.md).

## Обновление

Запустите ту же команду установки ещё раз — она обновит код и перерегистрирует сервер. Данные не трогаются.
После обновления перезапустите Claude Desktop; если менялся скилл — загрузите `dist/budget-tracker-skill.zip` заново.

## Удаление

```bash
uv run --directory ~/BudgetTracker python install/setup_claude.py --uninstall
```

Команда убирает MCP-сервер из Claude Desktop и Claude Code и скилл из Claude Code. Скилл в Claude Desktop удалите
вручную (Settings → Capabilities → Skills), затем удалите папку `~/BudgetTracker` (вместе с ней удалятся данные).

## Установка из скачанной копии / другого места

```bash
git clone https://github.com/sttell/BudgetTracker.git
./BudgetTracker/install/install.sh          # Windows: .\BudgetTracker\install\install.ps1
```

Переменные окружения установщика: `BUDGET_TRACKER_DIR` — папка установки, `BUDGET_TRACKER_REPO` — свой форк,
`BUDGET_TRACKER_REF` — ветка. Путь к данным можно переопределить переменной `BUDGET_DATA_DIR` в конфиге MCP-сервера.

## Где что лежит

| Что | Где |
|---|---|
| Данные (траты, настройки, курсы) | `~/BudgetTracker/data/` — JSON-файлы, не попадают в git |
| Лог веб-интерфейса | `~/BudgetTracker/data/web.log` |
| Конфиг Claude Desktop | macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`; Windows: `%APPDATA%\Claude\claude_desktop_config.json` |
| Скилл для Claude Code | `~/.claude/skills/budget-tracker/` |

## Ограничения

- Валюты: RSD, EUR, USD. Курсы — официальный средний курс Народного банка Сербии
  (через [kurs.resenje.org](https://kurs.resenje.org)); для пересчёта нужен интернет, курсы кешируются.
- Всё работает локально: Claude на телефоне до MCP-сервера на компьютере не достанет.

## Если что-то не работает

| Симптом | Что сделать |
|---|---|
| В Claude нет инструментов `budget` | Полностью перезапустите Claude Desktop; проверьте Settings → Developer — там же статус и логи MCP-сервера |
| «Порт 5050 занят другим процессом» | Остановите вручную запущенный `budget-web` (Ctrl+C в его терминале) — дальше агент будет поднимать веб сам |
| `uv: command not found` после установки | Откройте новый терминал (uv добавляется в PATH) или запустите установку ещё раз |
| Нет курса валюты | Нет интернета — попросите агента задать официальный курс НБС вручную: «официальный курс евро на 5 октября 117.5 динара» |
